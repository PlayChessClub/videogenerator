功能

🎙️

声音工作室

CosyVoice 声音克隆（voice enrollment）+ 文本转语音。支持公网音频 URL 或本地上传，音色状态自动轮询，音量 / 语速 / 音高可调。

🖼️

图片生成

文生图同步接口，无需轮询。模型可选 qwen-image-2.0 系列与 wan2.7-image 系列，尺寸张数可控，结果自动收录素材库。

🎬

视频生成

文生视频（wan2.6-t2v / wan2.7-t2v）与图生视频（wan2.6-i2v 系列及 flash 模型），异步任务 + 自动轮询 + 结果下载，分辨率 / 时长 / prompt 扩写可控。

✂️

剪辑时间线

把生成的视频按顺序拼接导出，支持「保留原声」或「整体替换配音」，纯 AVFoundation 实现（macOS 版）。

💰

消费预估值

发起生成前弹窗提示预计消耗 token 区间（±30%）与预估金额，确认后才调用模型，费用心中有数。

🧾

生成账单

每次确认生成自动记录明细（时间 / 模型 / 计量 / token 区间 / 预估金额 / 任务 ID），账本页可看今日 / 本月 / 累计汇总，一键导出 CSV 核对实际扣费。

🎲

试试手气

视频 / 图片生成页一键随机填入精选 Prompt，灵感卡住时点一下就有。

🔉

音色素材（macOS）

内置两款中文播音样音（沉稳男 Reed / 标准女 Sandy，系统 TTS 本机合成、无第三方版权）。试听满意可一键作克隆参考；也可「保存副本」把样音或自备 wav/mp3/m4a 放进可自定义的素材文件夹复用、重命名。

音色相关的音频都在哪？

声音流程里其实有三种对象——只有样本素材与合成成品会落到本地，克隆生成的那个“音色”不在本地：

对象存放位置说明
① 音色参考素材（克隆输入）本地（包内 VoiceSamples/；或「音色素材文件夹」）试听 / 上传做克隆的样本人声，不是音色本体。
② 已克隆的个性化音色（voice）阿里云（你的 DashScope 账户）App 只保存其 voice_id；「音色下拉 / 刷新列表」在读云账户。本地不生成可用音色文件。
③ 合成出的 mp3 成品本地（产物保存/语音 目录）选定 voice 朗读后落盘的最终音频。

克隆链路：本地素材 → 上传 OSS → createVoice（云端登记 voice）→ 得到 voice_id → 之后每次用该云端 voice 合成 mp3。「删除音色」只删云端记录，不动本地素材。

关于阿里云 Token Plan（重要）

ClipForge 的生成功能使用普通百炼按量付费 API Key（sk- 开头，端点 dashscope.aliyuncs.com），不使用 Token Plan 专属 Key（sk-sp- 开头）。阿里云官方规定 Token Plan 专属 Key 仅限在 Claude Code / Cursor / Qwen Code 等 AI 编程与智能体工具中交互式使用，禁止用于自定义应用程序后端或自动化脚本；且图像/视频生成模型无法通过文本类 Base URL 直接调用。

  • ClipForge 内生成 → 消耗普通百炼账户余额（按量付费）
  • 在 Claude Code / Cursor 里用 Token Plan 生图 → 消耗套餐 Credits（走 Skill 机制）
  • 不要把 sk-sp- 开头的 Key 填进 ClipForge，否则可能违反订阅条款导致封禁

下载与安装

所有版本安装包在 GitHub Releases 页发布。

🍎

macOS

下载 ClipForge-<版本>.pkg，双击按向导安装（先展示 Apache-2.0 许可协议，同意后输入管理员密码，装到 /Applications）。

装好后进入「设置」填入 DashScope API Key（百炼控制台创建，sk- 开头，存于钥匙串）。生成结果默认输出到 ~/Downloads/ClipForge/。

pkg 为 ad-hoc 未签名。首次打开若被 Gatekeeper 拦截：右键 → 打开，或在「系统设置 → 隐私与安全性」点「仍要打开」。
🪟

Windows

下载 clipforge-windows-amd64.zip（Intel/AMD）或 clipforge-windows-arm64.zip（ARM 设备），解压双击 exe，自动弹出内嵌 Chromium 应用窗口（关窗即退出）。

在「设置」填入 API Key 即可（web 版以明文 yml 存于 %APPDATA%\ClipForge\settings.yml，注意保管，勿提交到仓库）。
