# ClipForge · Windows 手动编译、打包与发布指南

> 适用版本:v2.0.0  ·  目标系统:Windows 10 1809+(强烈建议 Windows 11 22H2+)

这份指南假设你**不会用 GitHub Actions CI**,完全靠本地操作完成所有事情。
跟着步骤走,大概 30~50 分钟可以完成首次 Release。

---

## 0. 准备

### 0.1 系统要求
| 项目 | 最低 | 推荐 |
|---|---|---|
| 操作系统 | Windows 10 1809 | Windows 11 22H2+(Mica 体验) |
| 内存 | 4 GB | 8 GB+ |
| 磁盘 | 3 GB 可用 | 5 GB+ |

### 0.2 安装 .NET 8 SDK
打开 https://dotnet.microsoft.com/download/dotnet/8.0
下载 **.NET 8.0 SDK(x64)** 安装包,一路下一步。

装完打开 **PowerShell**(不是 cmd),验证:
```powershell
dotnet --version
# 应该输出 8.0.xxx
```

### 0.3(可选)安装 Visual Studio 2022
如果你想用 IDE 编译(更省事),装 https://visualstudio.microsoft.com/zh-hans/vs/
勾选工作负荷:
- **.NET 桌面开发**
- **Windows 应用开发 C#**(这个会带 Windows App SDK 1.6)

如果不用 IDE,纯靠命令行,跳过本节。

## 1. 上传源码到 GitHub

> 我们没有 CI,源码还是需要放在 GitHub 上,方便给用户下载 Release。

### 1.1 新建空仓库
浏览器打开 https://github.com/new
- Repository name: `videogenerator`(或你喜欢的名字)
- 选 **Public**
- **不要**勾选 Add a README / .gitignore / license(我们已经有了)
- 点 Create repository

### 1.2 在 Windows 机器上操作
把整个项目(包括 macOS `Sources/`、`Tools/`、`build.sh`、`README.md`、`LICENSE` 和新的 `Windows/`)
复制到 Windows 机器。任意位置,比如 `D:\projects\ClipForgeAI\`。

打开 **PowerShell**,进入项目根目录:
```powershell
cd D:\projects\ClipForgeAI
```

### 1.3 关联远程并推送
```powershell
# 如果你电脑上还没装 git:https://git-scm.com/download/win

git remote add origin https://github.com/<你的用户名>/videogenerator.git
```

## 2. 本地编译

> 两种方式任选一种。

### 方式 A:命令行(纯 .NET SDK,不需要 VS)

进入 `Windows` 目录:
```powershell
cd D:\projects\ClipForgeAI\Windows

# 1) 还原 NuGet 包
dotnet restore src\ClipForgeAI.Win.csproj

# 2) 编译(确认零错误)
dotnet build src\ClipForgeAI.Win.csproj -c Release -p:Platform=x64

# 如果你的电脑是 ARM(比如 Surface Pro X、骁龙本),把 x64 换成 ARM64
```

成功后 PowerShell 会显示 `Build succeeded. 0 Error(s)`,中间产物在
`src\bin\x64\Release\net8.0-windows10.0.19041.0\win-x64\`

### 方式 B:Visual Studio

1. 双击打开 `Windows\ClipForgeAI.Win.sln`
2. 工具栏下拉框选 **x64** / **Release**(或 Debug,都行)
3. 按 **F5** 启动调试,或 **Ctrl+F5** 不调试直接运行

> 第一次启动会拉 NuGet 包,需要联网,大概 1~2 分钟。

## 3. 发布成可分发的 .exe 目录(自包含)

> **自包含(self-contained)** = 用户双击 .exe 不需要单独装 .NET 运行时,
> 适合分发。

```powershell
cd D:\projects\ClipForgeAI\Windows

# 3.1) 准备一个干净的输出目录
$out = "$PWD\publish\x64"
if (Test-Path $out) { Remove-Item $out -Recurse -Force }

# 3.2) 发布 x64 版本
dotnet publish src\ClipForgeAI.Win.csproj `
  -c Release -r win-x64 `
  -p:Platform=x64 `
  -p:WindowsAppSDKSelfContained=true `
  -p:SelfContained=true `
  -p:PublishSingleFile=false `
  -p:WindowsPackageType=None `
  -o $out `
  --no-restore

Write-Host "已生成: $out"
```

> ARM64 机器(骁龙本、Surface Pro X):把 `x64` 替换成 `ARM64`,RID 替换成 `win-arm64`。
> 两套发布结果可以同时存在,各装各的。

发布后的目录结构(精简):
```
publish\x64\
├── ClipForge.exe              ← 启动入口
├── ClipForge.dll
├── *.dll                      ← Windows App SDK 运行时
├── Microsoft.UI.Xaml.dll
├── ...
├── Assets\app.ico
└── (其他 .NET / WinAppSDK 运行时文件)
```

> 双击 `ClipForge.exe` 就能跑。直接整个目录打包,丢给任何 Win10/11 用户都跑得起来。

## 4. 打成 zip

```powershell
# 用 PowerShell 自带的 Compress-Archive
$src = "$PWD\publish\x64"
$dst = "$PWD\publish\ClipForge-windows-x64-v2.0.0.zip"
if (Test-Path $dst) { Remove-Item $dst -Force }
Compress-Archive -Path "$src\*" -DestinationPath $dst -Force

# 看大小
Get-Item $dst | Select-Object Name, @{N="MB";E={[math]::Round($_.Length/1MB,1)}}
```

通常 100~200 MB(Windows App SDK 运行时比较大)。

## 5. 上传 Release 资产

### 5.1 在 GitHub 创建 Release
浏览器打开 https://github.com/<你的用户名>/videogenerator/releases/new

填写:
- **Tag**: `v2.0.0-windows`(注意:不要选 existing tag,选 "Create new tag")
- **Target**: `main`
- **Release title**: `ClipForge Windows v2.0.0`
- **描述**: 可以从 `Windows/README.md` 抄一段,或者用这个模板:
  ```markdown
  ## ClipForge · Windows v2.0.0

  AI 视频编辑助手 · Windows 11 首个正式版。

  - WinUI 3 + .NET 8 + Mica 系统材质
  - 声音克隆 / 语音合成(cosyvoice-v3.5-plus)
  - 图生视频(wan2.6-i2v)
  - 跨平台行为与 macOS 客户端(v1.1.1)完全一致

  ### 下载
  - **x64**:ClipForge-windows-x64-v2.0.0.zip
  - **ARM64**:ClipForge-windows-arm64-v2.0.0.zip

  ### 安装
  解压任意位置,双击 `ClipForge.exe` 即可。
  首次运行在「设置」里填入 DashScope API Key。
  ```

### 5.2 上传 zip
把第 4 步生成的 zip 拖进 **Attach binaries** 区域。

如果你同时编译了 x64 和 ARM64,**两个都拖进去**,用户在 Release 页能选自己架构的版本。

### 5.3 发布
- 勾选 **Set as the latest release**(可选)
- 点 **Publish release**

完成 ✅。用户访问你的仓库 Release 页面就能下载了。

## 6. 常见问题

### Q1:`dotnet build` 报 "Windows App SDK not found"
VS 2022 用户:确认装了 "Windows 应用开发 C#" 工作负荷。
纯命令行用户:第一次 restore 会自动拉包,需要联网;若被墙,配置 NuGet 镜像:
```powershell
dotnet nuget add source https://nuget.cdn.azure.cn/v3/index.json -n "azure-china"
```

### Q2:启动后窗口是白色,看不到 Mica
说明你在 Win10 或老版 Win11。Mica 自动回退到 Acrylic 应该也是半透明;
如果完全没效果,说明不是 Win11 22H2+,这时候背景就是实色 — 不是 bug,Windows 限制。

### Q3:声音合成进度条卡在某个值
正常。WebSocket 协议里 `task-finished` 之前不会有最终 100% 信号,
进度条用累计字节数估算,设了 95% 上限。最终保存成功后会刷成 100%。

### Q4:我 macOS 端的代码会不会因为这次更新坏掉?
不会。Windows 改动只在 `Windows/` 目录内,macOS 端的 `Sources/`、`Tools/`、
`build.sh` 完全没动。

### Q5:能不能用 GitHub Actions 自动编译?
可以,原 `.github/workflows/windows-build.yml` 已经写好(虽然被我撤回了)。
参见 `Windows/docs/配置自动CI编译.md`(如果存在)。

## 7. 调试技巧

- **看 API 请求/响应**:在 `DashScopeClient.SendAsync` 加 `Console.WriteLine(body)`
- **看 WebSocket 帧**:在 `CosyVoiceTtsService.ReceiveMessageAsync` 加日志
- **清掉保存的 Key**:删 `%APPDATA%\ClipForge\settings.dat`
- **看安装日志**:PowerShell 运行
  ```powershell
  Get-WinEvent -LogName Application -MaxEvents 50 | Where-Object { $_.ProviderName -match "ClipForge" }
  ```
